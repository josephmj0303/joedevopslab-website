VProfile GitOps Platform on AWS EKS

Production-grade GitOps implementation of the VProfile application on AWS EKS using Terraform, ArgoCD, GitHub Actions, Helm, Amazon ECR, SonarQube, and Slack Notifications.

Architecture

Project Overview

This project demonstrates an end-to-end GitOps workflow for deploying a Java-based application on AWS EKS. The platform follows GitOps principles where application changes are automatically deployed through ArgoCD after successful CI/CD validation and container image publication.

Technology Stack

Terraform GitHub Actions AWS EKS Helm ArgoCD Amazon ECR SonarQube Slack

Key Features

  • Infrastructure provisioning using Terraform
  • AWS EKS managed Kubernetes cluster
  • GitHub Actions based CI/CD pipelines
  • SonarQube quality gate validation
  • Docker image build and publishing to Amazon ECR
  • Helm-based Kubernetes deployments
  • ArgoCD Auto Sync and Self-Healing
  • AWS Load Balancer Controller (ALB Ingress)
  • IRSA (IAM Roles for Service Accounts)
  • Slack deployment notifications

Challenges & Learnings

  • Designing a complete GitOps workflow required separating application source code from deployment manifests and ensuring ArgoCD continuously synchronized cluster state with Git repositories.
  • Managing image version updates between GitHub Actions, Amazon ECR and Helm charts was challenging. I implemented automated image tag updates in the GitOps repository to trigger deployments without manual intervention.
  • Configuring ArgoCD auto-sync and self-healing features helped maintain cluster consistency and recover from manual configuration drift.
  • Integrating SonarQube quality gates into the CI pipeline improved code quality and prevented deployments when quality standards were not met.
  • Working with AWS EKS provided deeper understanding of Kubernetes networking, ingress management, load balancers, service discovery and container orchestration.
  • Implementing Slack notifications improved deployment visibility by providing real-time feedback on pipeline execution and deployment status.
  • This project strengthened my practical knowledge of GitOps principles, Infrastructure as Code, Kubernetes operations and production-style CI/CD automation.
